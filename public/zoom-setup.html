Connect each user’s Zoom account.

The integration is built. The site owner needs to create a Zoom app and configure its credentials before visitors can connect.

1. Create a user-managed app

In Zoom App Marketplace, choose Develop → Build App → General App → User-managed. Use matching Development credentials for testing or Production credentials for distribution.

2. Register the callback

Set this exact OAuth redirect URL, add it to the allow list, and enable strict matching:

https://meeting-minutes-followup.wiry-eagle-9459.chatgpt.site/api/zoom/callback

3. Grant read access

Add these user-level scopes. Admin and write scopes are unnecessary.

  • user:read:user
  • meeting:read:list_meetings
  • meeting:read:list_upcoming_meetings
  • cloud_recording:read:list_user_recordings
  • cloud_recording:read:list_recording_files

4. Configure runtime secrets

Add ZOOM_CLIENT_ID, ZOOM_CLIENT_SECRET, and ZOOM_WEBHOOK_SECRET to this site’s server runtime environment, then deploy to apply them. The encryption key and app origin are already configured. Keep secrets out of chat, frontend code, and source control.

Register this deauthorization/notification endpoint in Zoom:

https://meeting-minutes-followup.wiry-eagle-9459.chatgpt.site/api/zoom/webhook

5. Test, then enable distribution

Use Zoom’s Local Test flow first. Visitors sign in to their workspace, then authorize their own Zoom account. Access by people outside your developer account depends on Zoom’s beta/distribution rules and Marketplace review. Website publication alone does not enable unrestricted Zoom sign-in.

What gets cached

DuckDB in the browser saves fetched meeting records, imported transcripts and minutes, and analysis results on this device. The Saved library can search, reopen, export, or clear them. Use Cache available transcripts to save all completed transcripts in a fetched recording list. Zoom tokens stay encrypted on the server.

What Zoom makes available

Valid hosted meetings, upcoming invitations available to Zoom, and retained cloud recordings can be fetched. Transcripts must have been generated. A user’s complete attendance history, local recordings, deleted recordings, and other people’s private recordings are outside this connection’s access.
